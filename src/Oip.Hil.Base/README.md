# Oip.Hil.Base

Shared human-in-the-loop workflow contracts and services for OIP modules.

Includes the Temporal client and worker registration (`AddOipWorkflows`), the base class of workflows that wait for
users (`UserWorkflowBase`), user step kinds rendered by the `workflow-task` and `workflow-form` pages, the step service
and the controllers of the step pages and the workflow activity module.
